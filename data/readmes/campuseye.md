# CampusEYE

Repository: https://github.com/VirajBarapatre/CampusEYE
(Forked from https://github.com/mandy10-cmd/CampusEYE — original repo owner: mandy10-cmd)

Project Type: Team project — built by a team of 4
Tech Stack (overall project): Django, JavaScript

## Overview

CampusEYE is a full-stack campus management system designed to streamline student,
faculty, and admin operations — including attendance tracking, event management,
and notifications.

This was a collaborative team project, not a solo build. The repository on GitHub is
a fork of a teammate's original repo (mandy10-cmd/CampusEYE), reflecting that the
codebase was developed jointly across the team of four.

## My Contributions (Viraj Barapatre)

I was not responsible for the full system — my work on this project was focused on
two areas:

1. **Frontend (JavaScript / UI)**
   Built and worked on the JavaScript-driven user interface components for the
   campus management platform.

2. **Machine learning model development**
   Trained and tested several ML models for the platform, covering:
   - **Predictive analytics** — forecasting/predicting campus-related outcomes
     (e.g. trends in attendance, engagement, or similar operational metrics)
   - **Anomaly detection** — identifying unusual or outlier patterns in campus data
   - **Prompt generation** — generating prompts (e.g. for AI-assisted features
     within the platform)
   - Ran and tested **SmolVLM** and **YOLOv8** models for automated attendance
     detection from video feeds
